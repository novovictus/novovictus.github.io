# Project NOMAD

*Mobile Cyber Systems Laboratory*

**Status:** Planning and vehicle configuration

Project NOMAD is a mobile cyber systems laboratory built around a high-roof Ford Transit platform. The goal is a self-contained field workspace for cybersecurity, systems engineering, hardware and protocol work, networking, local compute, instrumentation, and related technical research.

## Vehicle baseline

Current platform configuration:

- 2027 Ford Transit T-250 Cargo Van
- 148-inch wheelbase, Long body
- High Roof
- 9,150 lb GVWR
- 3.5L EcoBoost V6
- Intelligent AWD
- 3.73 limited-slip axle
- Two-seat front cabin with 10-way power heated driver and passenger seats
- 31-gallon extended-range fuel tank
- Full-size spare tire and wheel
- Heavy-duty trailer tow package and factory trailer brake controller

## Factory upfit foundation

The current configuration intentionally preserves useful factory infrastructure for the eventual lab build:

- Dual 250A alternators
- Dual AGM batteries
- High-capacity upfitter switches
- Auxiliary fuse panel with high-spec interface connector
- Modified vehicle wiring system
- 400W Pro Power Onboard
- Auxiliary heater/A/C preparation with coolant and refrigerant stub lines
- Ford Connectivity Package with integrated hotspot capability
- Ford Security Package with theft alerts, Start Inhibit, and stolen-vehicle services

## Design direction

The cargo area will remain a purpose-built technical workspace rather than a generic trade-van shelving installation. Current planning priorities include:

- Isolated LiFePO4 house electrical system
- Alternator-fed DC-DC charging
- Shore-power input and inverter/charger
- Dedicated AC and DC distribution
- Environmental control suitable for occupied technical work and equipment
- Structured network, communications, and lab instrumentation
- Secure equipment storage and serviceable wiring paths
- Durable floor, wall, and ceiling treatments without sacrificing unnecessary interior volume

The factory electrical system will be treated as the vehicle-side source and control interface. Lab power, networking, and equipment systems will be designed as distinct upfit layers rather than extensions of the OEM battery system.

## Current phase

The project is still in configuration and architecture planning. Vehicle options are being selected to maximize useful factory provisions while avoiding packages that would constrain the eventual lab layout.

This note will remain the single project record until the build is far enough along to justify a larger documentation structure.
